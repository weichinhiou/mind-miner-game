## 盤點與決策

- Jean 指定在 `D:\Git\Game\mind-miner` 盤點 PRD 後實作。開工檢查發現僅有 PRD，沒有 `.git`、程式、AGENTS.md、README、框架、既有遊戲或正式入口。因此 Git 分支、HEAD、stash、origin 同步皆不適用；未建立 Git、commit、push、部署。
- 採無依賴 ES modules + Canvas + DOM，理由是此處為獨立空白專案，PRD 不需要後端或大型遊戲引擎。未引入 React、物理引擎或新平台。由 JJ 在 PRD 授權的本機 MVP 範圍內決定。
- 八位人物直接由 PRD 第 15 節 JSON 擷取，保留所有編輯注意事項與來源。未額外查證或重寫人物事實。啟用資料的 id 驅動抽樣，不寫死人物名單。
- 美術使用原創程式形狀、淡色山景、金色土層紋理與黑貓；無圖片載入依賴。這是水彩配色的初版程式美術，仍可替換為正式素材。人物姓名卡作為無頭像時的替代。
- 同盤用 Fisher–Yates 抽取兩位不同人物；所有人物等機率。隨機生成最多每物件 120 次，失敗或淺層藏書被擋則用安全盤面。桌機 960×540、手機 480×720，旋轉／resize 保留物件身份、貨物、分數、時間，座標以支點和場景尺寸重映射，需手動繼續。
- 存檔 schema 不符／損毀時保留原內容，停用本次持久化，改用記憶體。避免無提示刪除未知版本收藏。正常 60 秒結束更新最高分；提前結束只展示成績，收藏仍保留。
- 未確認 URL 時隱藏任意門與 Persona Lens 按鈕；只提供經確認的功能首頁 URL 設定，不捏造人物路由。
