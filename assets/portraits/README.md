# 八位人物頭像

來源：Jean 於 2026-10-03 提供「八位歷史人物.png」（Persona Lens 海報），原始大小 1672×941。

本專案保存完整原圖為 scholar-portraits-sheet.png，未重繪人物或修改圖中文字；以 CSS 圓形容器只顯示人物区域。data/scholars.json 的 portrait 設定裁切位置，app.js 共用 portrait 函式負責顯示。圖片錯誤時回到姓名卡，角色文字仍來自 PRD。

此圖由使用者提供並授權在本機遊戲使用；未另外取得外部授權資訊，對外發布前由 Jean 確認使用條件。原海報的標語不作為人物原話，人物介紹沿用 PRD。
